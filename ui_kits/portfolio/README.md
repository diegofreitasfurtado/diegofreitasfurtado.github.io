# UI Kit — Portfolio / Site Pessoal

Recriação hi-fi do site pessoal/portfólio de Diego Furtado.

## Estrutura

- `index.html` — Prototype interativo completo (home → projeto → sobre → contato)
- `Header.jsx` — Barra de navegação com logo
- `Hero.jsx` — Seção hero com tipografia grande
- `ProjectCard.jsx` — Card de projeto/análise
- `Footer.jsx` — Rodapé com links e motifs

## Design

- Fundo preto/navy como padrão
- Bebas Neue para títulos
- JetBrains Mono para corpo e labels
- Amarelo como cor de destaque/CTA
- Sombras offset sharp, sem border-radius
- Motifs geométricos decorativos como elementos de fundo

## Telas incluídas

1. **Home** — Hero + lista de projetos em destaque
2. **Projeto** — Caso de análise com dado + visualização placeholder
3. **Sobre** — Bio, habilidades
4. **Contato** — Formulário simples
