| `validate-portfolio.mjs` | Valida estrutura de `projects-data.js` antes de concluir uma manutencao |

## Regras locais

- Nao criar scripts que alterem identidade visual.
- Nao criar scripts que publiquem, apaguem ou movam arquivos automaticamente.
- Scripts daqui devem servir para validacao, checagem e apoio operacional.
- Toda mudanca aqui precisa de aprovacao explicita do Diego e registro no `CHANGELOG.md`.
